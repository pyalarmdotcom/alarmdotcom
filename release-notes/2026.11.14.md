# 2026.11.14

- **WebSocket diagnostics (#176).** Debug logs now show when Home Assistant unloads the entry, cleans up incomplete setup, or closes the current session for a reconnect. The WebSocket client logs its target state before canceling its tasks.
- **Water valves (#189).** The first WebSocket connection triggers a read-only refresh of discovered valves. This can correct a stale startup reading when Alarm.com returns newer data. The reporter later confirmed that the Moen Flo can still show Closed after startup while Alarm.com shows Open.
- **Camera troubleshooting (#190).** The README explains how to test the bundled WebRTC card against Alarm.com Live Video and report a gray screen or stream error.
