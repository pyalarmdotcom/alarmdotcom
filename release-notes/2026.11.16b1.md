# Alarm.com 2026.11.16b1: Upstream modernization beta

**Status: Candidate under validation.** These notes will accompany the first official upstream modernization prerelease when published. The GitHub release has **not** been published yet.

For the original Alarm.com integration community, active maintenance is resuming. This beta prepares the updated v4-based implementation, developed and tested since March 2026 in [the maintained repository](https://github.com/ibasebcast/ha-alarmdotcom), for use in the original project's HACS distribution.

## What's included

- Updates for Home Assistant 2026.11 compatibility, including device registry and entity API changes that prevent original v3.0.15 from loading on modern Core versions.
- The maintained integration's bundled Python library, modernized config and authentication flow, reconnect/state handling, device features, diagnostics, and regression tests.
- Expanded device and supported camera capabilities, including features developed in the maintained releases.
- Complete development history in [CHANGELOG.md](../CHANGELOG.md), with release notes retained and previous contributor credits preserved.

## Please test carefully

This is an **opt-in beta, not a stable update**. Please make a full Home Assistant backup first. Do not delete your existing Alarm.com configuration entry simply to test. Do not install the original and maintained distributions simultaneously in the same `alarmdotcom` folder.

We especially need feedback from users upgrading an existing **original v3.0.15** installation or one of the original v4 beta installations. Check that the integration loads, accounts authenticate, existing configurations remain usable, devices and entity IDs are preserved, and existing dashboards/automations still work. Also verify sensor updates and any safe device-specific functions you can test.

Report your Home Assistant version, installation method, previous integration version, steps taken, observed results, and sanitized logs. **Never post passwords, access tokens, cookies, MFA codes, camera credentials, or account/device identifiers.**

This unofficial integration is not a replacement for Alarm.com's official security monitoring or safety notifications.
